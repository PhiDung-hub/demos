❯ agent-os demo --fleet --plan --decision

Agent OS is a multi-agent control terminal built on WezTerm and Ratatui. It runs many Claude Code and Codex sessions from one keyboard-driven screen. I use it daily.

agent-os.mp4 50 sfleet · plan · logs · decision · key search · zen
❯ agent-os features
✓fleetOne view of every session, with sub-agent and workflow trees, live tokens/s, context, CPU and RAM.
✓decisionsAgents publish plans and questions through a CLI protocol into one Decision inbox, with options, a recommended answer and notes. Dangerous tool calls wait for approval.
✓viewerThe session viewer has Plan, Logs, Changes and Docs. The usage ledger counts each response once. Cross-agent verification has Claude grade Codex, and Codex grade Claude.
✓pluginsAn Agent OS Claude Code plugin, a WezTerm workspace manager with session restore, and Jev prompt review (Alt+G) and compaction.
✓configsOne installer merges Claude Code and Codex settings, hooks and permissions, and backs up every file it changes.
✓leanCore contracts are verified in Lean 4: 57 kernel-checked theorems, with no sorry. The plan proof caught a real acknowledgement bug, which is now fixed with an end-to-end regression test. 2:lean-verify
✓platformsRuns on Linux, macOS, native Windows 11 and WSL2.

The sessions in the video are the repo's end-to-end test fixture (synthetic agents), so no real work is shown. The source is private.

❯ agent-os verify lean FILE.lean ◆ upcoming

A Lean 4 verification platform is coming to Agent OS. It runs Lean as a formal-evidence engine beside Kani and Verus. It kernel-checks a model with a pinned toolchain and counts it as verified only when every theorem's axiom audit is clean. No model judge is involved.

lean-verify.mp4 42 spass · sorry refused · custom axiom refused · source hash gate
❯ verify lean --rules
✓passesThe kernel accepts the file, and every theorem depends only on propext, Quot.sound or Classical.choice.
✗refusedsorry, admit, custom axioms, an empty audit, a timeout or unrecognized output. Any of these leaves the proof unconfirmed.
✓sandboxRuns in a copied workspace with a private home, a 30 s limit and bounded output. Nothing is installed automatically.
✓correspondenceThe repo gate pins the sha256 of every reviewed source file. If a modelled file changes, the check fails until the proof is reviewed again.
◆in progressLean evidence in cross-agent verification reports, with formal scope and assumptions shown next to judge verdicts.
❯ verify lean --proved-so-far
accounting
maxima are idempotent, commutative, associative and monotone; work saturates at u64; fresh input never goes negative
plan
a live plan is acknowledged only when all parent and child steps are done (caught the bug)
documents
a different session cannot update a stamped document; escaped text cannot open an HTML tag
render cache
exact reuse on a hit, bounded retained bytes, no Chrome or full decode for selection and zoom
total
57 theorems · 506 lines of Lean · standard axioms only

These are proofs of explicit models, and source hashes guard the link to the code. They do not prove the compiler, IO or the parsers.

❯ trading-terminal demo --read-only

A keyboard-first Hyperliquid perps trading terminal. It is a static Svelte 5 app on Cloudflare Workers that talks to the exchange over one WebSocket, with no backend.

❯ trading-terminal features
✓executionMarket, limit, scale, chase, stop/take and TP/SL tickets, across perps, HIP-3 and spot markets.
✓hotkeysEvery load starts disarmed. Order keys need ` to arm and queue per coin in press order. The function search takes a regex.
✓keysTrades through a browser-held agent key that can place and cancel orders but cannot withdraw.
✓rate limitMarket lists, candles and fills are cached locally, which cut a warm reload from 348 to 20 units of the per-IP rate-limit budget.
✓ai coachA local MCP companion for Claude Code and Codex. It stages tickets, chart marks and coaching notes in the browser, and it never holds a trading key.
