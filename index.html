❯ agent-os --demo

Agent OS: a multi-agent control terminal (WezTerm, Rust and Ratatui). Phil Ho.

  • One keyboard-driven dashboard for many Claude Code and Codex sessions: a fleet view with sub-agent and workflow trees, plus live tokens/s, context, CPU and RAM for each session.
  • Agents publish plans and ask questions through a CLI protocol. Questions land in one Decision inbox with options, a recommended answer and notes. Dangerous tool calls are held for approval.
  • A session viewer with Plan, Logs, Changes and Docs. A usage ledger counts each response once, and in cross-agent verification Claude grades Codex and Codex grades Claude.
  • Core contracts are verified in Lean 4: 57 kernel-checked theorems, with no sorry and only standard axioms. The plan proof found a real acknowledgement bug, which was fixed with an end-to-end regression test.
  • Runs on Linux, macOS, native Windows 11 and WSL2.

The video shows the fleet overview, the plan viewer, the logs, the Decision page with a pending question, the key search and Zen mode. The sessions are the repo's end-to-end test fixture (synthetic agents). The source is private.
